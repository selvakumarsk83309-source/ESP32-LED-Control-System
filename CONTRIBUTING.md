# Contributing

Thank you for your interest in the ESP32 LED Control System. Contributions of all sizes are welcome, including bug fixes, documentation improvements and new ideas.

## How to Contribute

1. **Fork** the repository on GitHub.
2. **Clone** your fork:
   ```bash
   git clone https://github.com/<your-username>/ESP32-LED-Control-System.git
   ```
3. **Create a branch** for your change:
   ```bash
   git checkout -b feature/your-change
   ```
4. **Make your changes** and test them on real hardware where possible.
5. **Commit** with a clear message:
   ```bash
   git commit -m "Add short description of your change"
   ```
6. **Push** your branch:
   ```bash
   git push origin feature/your-change
   ```
7. Open a **Pull Request** and describe what you changed and why.

## Guidelines

- Keep the code beginner friendly and well commented.
- Do not add unnecessary libraries or external web dependencies.
- Keep pin numbers, Wi-Fi details and file paths consistent across the code and documentation.
- Only add photos and results that come from real hardware.
- Follow the existing code style (2-space indentation, descriptive names).

## Reporting Issues

Open a GitHub Issue and include:

- A clear description of the problem
- Your board model and Arduino IDE / ESP32 package versions
- Steps to reproduce
- Serial Monitor output or error messages
